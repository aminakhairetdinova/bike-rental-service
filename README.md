# Сервис проката велосипедов

Система учёта и управления сервисом проката велосипедов на Python.

## Функциональность

- Создание велосипедов (городские, горные, электро)
- Управление станциями проката
- Аренда с расчётом стоимости
- Уведомления и логирование
- Сохранение/загрузка данных
- Проверка прав доступа

## Запуск

```bash
python main.py
